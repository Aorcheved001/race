# 磁力计 yaw 查表补偿与科目三矫正阶段计划书

## 1. 目标

当前 2D 磁力计椭圆校准已经能把 XY 数据基本拉圆，但实测 90 度分段旋转时仍存在象限非线性误差：整体一圈回环误差较小，但每 90 度分段误差会出现压缩和拉伸。继续只调 hard iron / soft iron 很难完全解决这个问题。

本计划目标是在现有 2D 校准基础上，增加一层磁航向查表补偿：

```text
校准后 mag_x/mag_y/mag_z
    -> 计算 mag_yaw_raw
    -> 使用 LUT 修正磁航向非线性误差
    -> 得到 mag_yaw_corrected_rel
    -> 仅在静止矫正阶段用于修正 gyro_yaw 漂移
```

科目三运行策略为：

```text
DRIVE 阶段：gyro-only 记录 INS 轨迹
CHANGE 阶段：完成掉头/换向
YAW_CORRECT 阶段：车辆静止，使用 LUT 后磁航向/RTK 监督慢慢纠正 yaw 漂移
FOLLOW 阶段：同步后的 gyro-only 循迹
```

核心原则：

- 运动阶段不依赖磁融合，避免电机、线束、车体磁扰影响实时 yaw。
- 静止矫正阶段才启用磁 yaw 纠正，车辆静止时长不限，可以慢慢收敛。
- RTK 用于离线建立 LUT 和在线监督/验证，但 FOLLOW 不强依赖 RTK。
- LUT 修正磁力计角度误差，不直接替代 gyro_yaw。

## 2. yaw 数据定义

后续 C 端和 Python 端必须统一以下 yaw 含义，禁止混用。

| 名称 | 含义 | 单位 | 用途 |
|---|---|---|---|
| `yaw_gyro` | 原始陀螺积分 yaw，允许包含零偏修正，但不吃磁力计 | deg/rad | DRIVE/FOLLOW 主航向 |
| `mag_yaw_raw` | 磁力计绝对磁航向，未减启动零点 | deg/rad | LUT 输入推荐位置 |
| `mag_yaw_rel` | 相对启动方向的磁航向 | deg/rad | 上位机观察、矫正参考 |
| `mag_yaw_corr_rel` | LUT 修正后的相对磁航向 | deg/rad | YAW_CORRECT 阶段修正参考 |
| `yaw_fused` | 临时融合 yaw，只在矫正阶段使用 | deg/rad | 收敛后的同步目标 |
| `rtk_yaw_ins` | RTK 转到 INS 坐标系的相对航向，但包含 RTK 安装偏角 | deg/rad | 原始 RTK yaw |
| `rtk_yaw_ref` | 扣除 RTK 安装偏角后的参考航向 | deg/rad | LUT 真值 |

角度统一使用 wrap 到 `[-180, 180]` 或 `[-pi, pi]` 的差值计算：

```c
error = normalize_angle(a - b);
```

不能直接相减后不归一化，否则跨越 +/-180 度时会出现假大误差。

## 3. RTK 安装偏角标定

RTK 双天线航向存在安装误差。天线基线方向不一定与车体正前方向完全一致，因此 `rtk_yaw_ins` 不能直接作为磁力计查表真值。

采用方案 A：在定原点阶段估计 RTK 相对 INS 坐标系的安装偏角。

### 3.1 标定时机

在科目三定原点 / 起始对齐阶段：

1. 车辆静止。
2. `gyro_yaw` 已经初始化或归零。
3. RTK yaw 有效。
4. 连续采集 1 到 2 秒数据。
5. 取多帧差值的 median 作为偏角。

### 3.2 计算公式

```text
rtk_mount_offset = median(normalize(rtk_yaw_ins - yaw_gyro))
rtk_yaw_ref      = normalize(rtk_yaw_ins - rtk_mount_offset)
```

如果定原点后 `yaw_gyro = 0`，则近似为：

```text
rtk_mount_offset = median(rtk_yaw_ins)
```

这个偏角不一定等于物理安装角，但它能把 RTK yaw 对齐到当前 INS 相对坐标系，满足科目三相对航向使用需求。

### 3.3 有效性要求

用于计算 `rtk_mount_offset` 的帧必须满足：

```text
车辆静止
RTK pos_valid = 1
RTK yaw_valid = 1
gyro_yaw 标准差较小
rtk_yaw_ins 标准差较小
采样数量 >= 25 帧，推荐 >= 50 帧
```

若 RTK 无效，不更新安装偏角，保留上一次有效值或进入无 RTK 降级模式。

## 4. 数据发送格式

### 4.1 基本原则

当前系统 4ms 更新一轮，40ms 发送一次即可。严格时间戳不是第一优先级，但建议发送 `seq` 或 `tick_ms`，用于发现丢包、卡顿和数据错位。

### 4.2 yaw + RTK 调试帧

建议新增 C 端发送帧：

```text
yawrtk:seq,tick_ms,phase,yaw_gyro,mag_yaw_raw,mag_yaw_rel,mag_yaw_corr_rel,yaw_fused,rtk_yaw_ins,rtk_yaw_ref,rtk_valid,mag_x,mag_y,mag_z
```

单位建议全部用度，便于上位机直接分析：

```text
yawrtk:1234,49360,YAWCR,-12.34,-62.10,-15.20,-13.10,-13.05,-10.80,-13.00,3,480.1,760.2,-445.4
```

字段说明：

| 字段 | 说明 |
|---|---|
| `seq` | 发送序号，每帧 +1 |
| `tick_ms` | 系统毫秒或 4ms tick 换算值 |
| `phase` | 当前阶段，如 DRIVE/CHANGE/YAW_CORRECT/FOLLOW |
| `yaw_gyro` | gyro-only yaw |
| `mag_yaw_raw` | 倾斜补偿后的原始磁 yaw，LUT推荐输入 |
| `mag_yaw_rel` | 未 LUT 修正的相对磁 yaw |
| `mag_yaw_corr_rel` | LUT 修正后的相对磁 yaw |
| `yaw_fused` | 矫正阶段临时融合 yaw |
| `rtk_yaw_ins` | 原始 RTK INS yaw，含安装偏角 |
| `rtk_yaw_ref` | 扣除安装偏角后的 RTK yaw |
| `rtk_valid` | bit0=pos valid, bit1=yaw valid |
| `mag_x/y/z` | 校准后的磁力计数据 |

### 4.3 数据降级

如果暂时没有 RTK 或 RTK 无效：

```text
rtk_valid = 0
rtk_yaw_ins = 0
rtk_yaw_ref = 0
```

但 yaw 和 mag 数据仍正常发送，便于分析磁力计与 gyro 的关系。

## 5. LUT 生成方案

### 5.1 数据来源

LUT 生成需要多轮数据，推荐覆盖不同方向、不同位置、不同操作轮次。

输入数据：

```text
yawrtk 日志：yaw_gyro, mag_yaw_rel, mag_yaw_corr_rel, yaw_fused, rtk_yaw_ref, valid, mag_x/y/z
```

生成 LUT 时使用：

```text
输入角：mag_yaw_raw 或 mag_yaw_rel
真值角：rtk_yaw_ref
误差：normalize(rtk_yaw_ref - mag_yaw_rel)
```

最终 LUT 定义建议为：

```text
mag_yaw_corr = normalize(mag_yaw + lut[mag_yaw])
```

也就是 LUT 存储“需要加到磁 yaw 上的修正量”。

### 5.2 为什么不直接用 yaw_fused 建表

`yaw_fused` 已经受 gyro 和磁融合影响，不是真值。建表必须用 RTK 修正后的参考航向：

```text
rtk_yaw_ref = rtk_yaw_ins - rtk_mount_offset
```

`yaw_fused` 只能用于评估修正效果，不能作为 LUT 真值。

### 5.3 分桶策略

不建议直接用 1 度桶硬生成 360 个独立值，因为单桶样本可能不足，容易产生尖峰。

推荐：

```text
原始统计桶：5 deg 或 10 deg
每桶统计 median error
剔除异常点
环形插值到 1 deg
环形平滑
生成 360 项 C 数组
```

每桶至少要求：

```text
样本数 >= 20
误差标准差 <= 5 deg，超过则标记低可信
RTK valid 有效
磁半径在正常范围内
```

### 5.4 异常点剔除

建表前过滤：

```text
RTK yaw invalid 的点剔除
车辆剧烈运动/角速度过大点可剔除
磁半径偏离中位数过大的点剔除
mag_z 极端异常点剔除
yaw 差值绝对值 > 45 deg 的点先标记为可疑
```

注意：不能只保留“看起来误差小”的点，否则 LUT 会过拟合。

### 5.5 空桶处理

若某些方向没有样本：

```text
优先用相邻有效桶环形插值
若连续缺口过大，例如 > 60 deg，则本轮数据不能生成正式 LUT
```

### 5.6 LUT 验收指标

生成 LUT 前后必须报告：

```text
修正前 mag_yaw_rel vs rtk_yaw_ref：
  mean error
  median abs error
  p95 abs error
  max abs error

修正后 mag_yaw_corr_rel vs rtk_yaw_ref：
  mean error
  median abs error
  p95 abs error
  max abs error

LUT 本身：
  覆盖桶数量
  最大连续缺口
  相邻 LUT 最大跳变
  平滑前后曲线图
```

建议验收标准：

```text
覆盖 >= 330 deg
p95 abs error <= 3~5 deg
max abs error <= 8~10 deg
相邻 LUT 跳变不出现明显尖峰
```

## 6. C 端 LUT 应用位置

### 6.1 推荐位置

LUT 应用在磁航向原始计算之后、减初始磁航向之前：

```text
mag_yaw_raw = compute_tilt_compensated_mag_yaw(...)
mag_yaw_corr_raw = mag_yaw_raw + lut_correction(mag_yaw_raw)
mag_yaw_corr_rel = normalize(mag_yaw_corr_raw - initial_mag_yaw_corr_raw)
mag_yaw_corr_rel_filtered = lowpass(mag_yaw_corr_rel)
```

这样 LUT 修正的是传感器方向误差，而不是低通后的相对结果。

### 6.2 需要新增/修改的数据

`Ins.c` 中建议新增：

```c
static float s_mag_yaw_corr_raw = 0.0f;
static float s_mag_yaw_corr_rel = 0.0f;
static float s_mag_yaw_corr_rel_filtered = 0.0f;
static float s_initial_mag_yaw_corr = 0.0f;
static uint8_t s_mag_yaw_lut_enabled = 0u;
```

新增接口：

```c
void Ins_set_mag_yaw_lut_enabled(uint8_t enable);
void Ins_get_yaw_debug_layers(...);
float Ins_get_mag_yaw_corrected_rel(void);
```

### 6.3 LUT 查表方式

C 端不要只做整数硬查，推荐线性插值：

```text
idx0 = floor(yaw_deg)
idx1 = idx0 + 1
frac = yaw_deg - idx0
corr = lut[idx0] * (1 - frac) + lut[idx1] * frac
```

角度要处理环形：

```text
359 deg 和 0 deg 相邻
```

### 6.4 LUT 开关

LUT 可以全程作用于磁 yaw，但磁 yaw 对最终 yaw 的强修正只在 YAW_CORRECT 阶段启用。

推荐：

```text
DRIVE：LUT 可计算，但不修正最终 yaw
CHANGE：LUT 可计算，但不修正最终 yaw
YAW_CORRECT：LUT + yaw 融合启用
FOLLOW：关闭磁融合，gyro-only；LUT 可继续计算用于监控
```

## 7. 科目三状态机设计

### 7.1 阶段定义

新增阶段：

```text
DRIVE_RECORD
CHANGE
YAW_CORRECT
FOLLOW
FINISH
```

`YAW_CORRECT` 是 CHANGE 完成后、FOLLOW 开始前的静止矫正阶段。

### 7.2 DRIVE 阶段

DRIVE 阶段只使用 gyro_yaw 记录 INS 轨迹。

原因：

- 电机/线束/场地磁扰可能影响磁力计。
- 运动中磁 yaw 不稳定时，强融合会污染轨迹。
- DRIVE 是录制参考路径，优先保证短时间 gyro 连续性。

### 7.3 YAW_CORRECT 阶段

进入条件：

```text
CHANGE 完成
车辆静止
用户/遥控/上位机确认进入矫正
```

矫正过程：

```text
1. 开启 LUT 后磁 yaw 参考
2. 开启 yaw 临时融合
3. 计算 yaw_error = normalize(mag_yaw_corr_rel - yaw_gyro)
4. 慢慢把 yaw_fused 拉向 mag_yaw_corr_rel
5. 等待误差和波动稳定
6. 将 yaw_fused 同步回 gyro_yaw 层
7. 关闭磁融合
8. 进入 FOLLOW
```

完成条件建议：

```text
静止持续 >= 2s
连续 >= 50 帧满足稳定条件
abs(yaw_fused - mag_yaw_corr_rel) < 3 deg
yaw_error 标准差 < 1.5 deg
磁半径质量正常
若 RTK 有效，则 abs(yaw_fused - rtk_yaw_ref) < 5 deg
```

车辆静止时长没有限制时，建议宁愿等稳定，不要急切进入 FOLLOW。

### 7.4 矫正完成后的同步

不能只改 `s_state.yaw`。必须同步所有后续会影响 yaw 的状态。

至少同步：

```c
s_bias_corrected_yaw = yaw_corrected;
s_yaw_ekf.x[0] = yaw_corrected;
s_yaw_ekf.yaw_predict = yaw_corrected;
s_state.yaw = yaw_corrected;
```

如果六轴卡尔曼内部 yaw 还会被读取，也应同步：

```c
s_kalman_6axis.yaw_gyro = yaw_corrected;
s_kalman_6axis.Xk[2] = yaw_corrected;
s_kalman_6axis.Xk_[2] = yaw_corrected;
```

否则会出现矫正后一帧又跳回旧 gyro_yaw 的问题。

### 7.5 FOLLOW 阶段

FOLLOW 阶段默认 gyro-only。

```text
最终 yaw = 同步后的 gyro_yaw 积分
磁 yaw 只做监控，不强行参与闭环
RTK 可用于上位机评估，但不作为实时必须条件
```

## 11. 验收流程

### 11.1 LUT 建表验收

1. 定原点，估计 `rtk_mount_offset`。
2. 采集多轮低速转向/原地旋转数据。
3. 生成 LUT。
4. 检查报告：

```text
有效样本足够
角度覆盖 >= 330 deg
修正后 p95 <= 3~5 deg
无明显尖峰
```

### 11.2 静止矫正验收

1. 先人为制造 gyro_yaw 漂移或使用 CHANGE 后自然漂移。
2. 进入 YAW_CORRECT。
3. 查看：

```text
yaw_gyro 慢慢被 yaw_fused 拉回
mag_yaw_corr_rel 稳定
rtk_yaw_ref 与 yaw_fused 接近
完成后同步 gyro_yaw，无回跳
```

### 11.3 FOLLOW 验收

1. 矫正完成后进入 FOLLOW。
2. 确认 FOLLOW 初始 yaw 与参考路径一致。
3. 对比轨迹是否减小切弯/偏航导致的横向误差。

## 12. 回退方案

任何阶段异常时必须能回退到 gyro-only：

```text
RTK 无效：不更新 rtk_mount_offset，不用 RTK 做完成判据
磁半径异常：暂停 YAW_CORRECT，不同步 yaw
LUT 失效：关闭 LUT，使用原始 mag_yaw_rel 或直接 gyro-only
矫正不收敛：允许人工确认或重新进入矫正阶段
```

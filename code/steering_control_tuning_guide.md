# 转向控制调试指南（steering_control 模块）

> 模块：`code/control/steering_control.c / .h`
> 硬件方案：直流电机 + 绝对值编码器（模拟舵机效果）
> 控制算法：PD 闭环 + 陀螺仪前馈
> 控制周期：4ms

---

## 一、整体架构

```
目标角度(°) ──→ [PD控制器] ──→ PWM限幅 ──→ DIR+PWM驱动电机
     ↑              │                          │
     │              ↓                          ↓
     │        误差 = 目标 - 实际         陀螺仪前馈(gyro_z)
     │                                        │
     └──── 绝对值编码器(4096分辨率) ←─────────┘
```

**数据流**：
1. 绝对值编码器读取 0~4095 的原始值
2. 以 `g_zero_raw` 为参考零点，换算成角度（度）
3. 计算误差 = 目标角度 - 当前角度
4. PD + 陀螺仪前馈算出 PWM 输出
5. 驱动电机转动，改变前轮角度
6. 编码器再次读取新角度 → 形成闭环

## 二、调参步骤

### Step 0：架空前轮

调试全程把车架空（前轮离地），防止车子跑飞。

### Step 1：验证编码器方向

烧录代码后，通过串口/屏幕打印 `steering_get_current_angle()`，手动转前轮观察：

| 操作 | 期望现象 |
|------|----------|
| 前轮摆正 | 角度 ≈ 0° |
| 前轮向右转 | 角度 > 0（正值） |
| 前轮向左转 | 角度 < 0（负值） |
| 转一圈回到原位 | 角度 ≈ 0° |

**问题排查**：
- **方向反了**（向右显示负值）：在 `steering_control.c` 第 91 行，`current_angle` 前加负号
- **角度跳变 360°**：零位设在编码器 0/4095 边界附近，重新标定零位到中间值

### Step 2：零位标定

1. 用手把前轮摆到正前方
2. 调用 `steering_set_zero_at_current()`（可绑定到某个按键）
3. 确认 `steering_get_current_angle()` 回到 0°

### Step 3：只开 P 项

临时修改 `steering_control()` 第 107~110 行：

```c
// 调试阶段：只用 P
float output = KP * error;

// 完整版本先注释掉：
// float derivative = (error - g_last_error) / 0.004f;
// float output = KP * error + KD * derivative + GKD * imu660.data_Ripen.gyro_z;
```

**KP 调节方法**：

| 阶段 | KP 值 | 操作 | 观察 |
|------|-------|------|------|
| 起步 | 10.0 | `steering_set_target(10)` | 轮子动了吗？方向对吗？ |
| 增大 | 20.0 | 同样操作 | 响应是否更快 |
| 继续 | 30.0 | 同样操作 | 能否到位 |
| 目标 | 50.0 | 同样操作 | 到位快速，允许 1~2° 稳态误差 |

**方向验证**（最重要的一步）：
- 设置 `steering_set_target(10)`（目标 10° 右转）
- 如果前轮向右转 → 方向正确
- 如果前轮向左转 → 电机极性反了，改第 119 行：`dir = (output >= 0.0f) ? 0 : 1;`

**好的 KP 表现**：目标 10°，轮子较快到位，允许有 1~2° 稳态误差（PD 没有 I 项，有静差是正常的）

**KP 太大的表现**：轮子到位后反复左右抖动

**KP 太小的表现**：轮子转动无力，到不了目标角度

### Step 4：加入 D 项

恢复 D 项，KD 从 0 开始：

```c
float derivative = (error - g_last_error) / 0.004f;
float output = KP * error + KD * derivative;  // 暂时不加陀螺仪
```

**KD 调节方法**：

| 阶段 | KD 值 | 观察 |
|------|-------|------|
| 起步 | 0.1 | 响应比纯 P 更"紧"了吗 |
| 增大 | 0.3 | 超调减少 |
| 继续 | 0.5 | 到位时不再来回弹 |
| 上限 | 1.0 | 超过可能引起高频抖动 |

**KD 的作用**：抑制超调和震荡。P 项大时轮子到位后会"过头"再弹回来，D 项能阻尼这个过程。

**KD 太大的表现**：响应变慢、轮子"犹豫"、高频抖动（D 项对编码器噪声敏感）

**KD 太小的表现**：和纯 P 差不多，超调明显

### Step 5：加入陀螺仪前馈

恢复完整版本：

```c
float output = KP * error + KD * derivative + GKD * imu660.data_Ripen.gyro_z;
```

**GKD 调节方法**：

| 阶段 | GKD 值 | 操作 | 观察 |
|------|--------|------|------|
| 起步 | 1.0 | 手动旋转车身 | 前轮是否微调补偿 |
| 增大 | 3.0 | 同样操作 | 补偿效果是否明显 |
| 继续 | 5.0 | 同样操作 | 车身旋转被有效抵消 |
| 上限 | 10.0 | 同样操作 | 过大反而引起乱摆 |

**陀螺仪前馈的作用**：车身自身旋转（如差速转向导致偏航）时，`gyro_z` 检测到角速度，前馈项直接补偿转向，减少偏差。

**GKD 太大的表现**：车身稍有旋转前轮就大幅摆动，不稳定

**GKD 太小的表现**：和前一步差不多，陀螺仪几乎不起作用

### Step 6：整车地面测试

前轮离地测试通过后，把车放到地面：

1. `steering_set_target(0)` → 车子直线行驶
2. 遥控设置不同角度 → 转向是否跟手
3. 观察 `steering_get_current_angle()` 是否跟随 target

## 三、常见问题速查

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| **轮子抖动（高频）** | KD 太大或编码器噪声 | 降低 KD；或对编码器读数加 3 点均值滤波 |
| **轮子来回摆动（低频震荡）** | KP 太大 | 降低 KP（每次减 5~10） |
| **转向方向反了** | 电机 PWM/DIR 极性反了 | 改 `dir` 的逻辑，或交换电机两根线 |
| **编码器角度反向** | 编码器安装方向反了 | `current_angle` 前加负号 |
| **角度跳变 360°** | 零位在编码器 0/4095 边界附近 | 重新标定零位到中间值（~2048） |
| **有稳态误差** | PD 没有 I 项 | 正常。如需消除可加 I 项（但可能引起超调） |
| **陀螺仪前馈导致乱摆** | GKD 太大或 IMU 零偏未校准 | 降低 GKD；确认 `imu_gyro_z_autocalib` 已执行 |
| **上电后前轮不在正位** | 上电时车轮是歪的 | 调用 `steering_set_zero_at_current()` 重新标定 |

## 四、参数推荐起点

```c
#define KP      50.0f    // 起点值，可根据实际调整 30~80
#define KD      0.5f     // 起点值，可根据实际调整 0.2~1.0
#define GKD     5.0f     // 建议从 3~5 开始，不要直接上 10
```

---

## 五、推荐的上电流程

```
1. IMU 初始化 + 零偏校准（已有）
2. 绝对值编码器初始化
3. 确保上电时前轮是正前方
4. steering_init() 内部自动采集零位
5. 如果发现零位不准 → 调用 steering_set_zero_at_current() 重新标定
6. 如需微调 → 调用 steering_set_zero_offset(偏移量)
```

## 六、角度限制切换（掉头模式）

```c
// 默认模式：最大 30 度
steering_set_max_angle(30.0f);

// 掉头模式：最大 45 度
steering_set_max_angle(45.0f);
```

在赛道不同段切换角度限制，直线段用小角度保证稳定，弯道/掉头段放宽限制。
